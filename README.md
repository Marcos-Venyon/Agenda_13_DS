# 🎬 Portal de Entretenimento Digital

Projeto de uma página web responsiva focada em centralizar conteúdos sobre **Filmes e Séries**, **Música e Podcasts** e **Games e Tecnologia**.

---

## 🚀 Sobre o Projeto

Este portal foi desenvolvido utilizando HTML5 e CSS3. O layout é organizado em um sistema de colunas usando **Flexbox**, proporcionando uma navegação clara e limpa.

### 💡 Destaques de Aprendizado no Código:
* **HTML5 Semântico:** Uso de tags como `<header>`, `<main>`, `<section>`, `<article>`/`<h2>` e `<img>`.
* **Estilização em CSS:**
  * **CSS Externo:** Importado através de `reset.css` e `estilo.css`.
  * **CSS Interno:** Declarado no `<head>` para a classe `.subtitulo`.
  * **CSS Inline:** Aplicado diretamente na tag `<h1>` do cabeçalho.
* **Layout Flexbox:** Utilizado na classe `.container-flex` para alinhar as três seções lado a lado.
* **Imagens Dinâmicas:** Uso de imagens otimizadas integradas via Unsplash API.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3** (Flexbox, Estilos Globais, Reset CSS)
